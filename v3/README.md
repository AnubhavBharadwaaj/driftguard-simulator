# Sahodrift v3

Sahodrift, formerly DriftGuard, is the v3 research and evaluation track for SIH26170.

The published v2 result at `out/driftguard_results_v2.json` is immutable. All v3 code and generated artifacts belong under `v3/` and `out/v3/`.

## Current checkpoint

WP0 is in progress. The Python 3.11 environment has been recreated from the pinned v2 requirements, the five seed simulator remains unchanged, and the seed 0 regression run completed without modifying v2 outputs.

Human gated datasets are tracked separately. CORA is public under CC BY 4.0 but Chrome blocks its download redirect in the controlled browser. Aalborg requires an IEEE account. Bosch requires Kaggle sign in and competition rule acceptance.
